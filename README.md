### 📄 Featured Work

- **[AI Document Q&A Assistant (RAG)](https://github.com/FatimaSagheer/document-intelligence-platform)**
  Full-stack RAG system for question answering grounded in user-uploaded documents (PDF, DOCX, TXT). Text extraction, 500-word sliding-window chunking, local MiniLM embeddings (384-dim), pgvector cosine-similarity search on Supabase Postgres, and answers generated by Llama 3.3 70B (via Groq) strictly from retrieved context, with source citations to reduce hallucination. JWT-secured endpoints, queries scoped by user ID, SSL-encrypted database connections. Next step: extending it to a medical corpus (WHO/PubMed) with structured evaluation and hallucination/confidence detection.

- **EV Charging Demand Forecasting (Python)**
  Time-series forecasting of daily EV charging demand (kWh) with data cleaning, EDA and a time-based train/test split. Compared seven models (seasonal naive, moving average, ARIMA, SARIMA, ETS, Prophet, LSTM). SARIMA performed best (RMSE 175.4, MAPE 19.9%), about 18% lower RMSE than the seasonal-naive baseline.

- **[SolarIQ](https://github.com/FatimaSagheer/SolarIQ)**
  Real-time IoT solar monitoring platform (MEAN stack) with WebSocket live data visualization, JWT auth, automated email alerting, and automated tests (Jest, Supertest).

- **[TaskFlow](https://glistening-stillness-production-4cb2.up.railway.app/)**
  Full-stack task management app with authentication and real-time status updates, deployed live on Railway.
